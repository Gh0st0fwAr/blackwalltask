# Игра «Пятнашки» на Vue 2 и SCSS 🧩

Классическая головоломка «Пятнашки» (15-puzzle), реализованная на фреймворке **Vue 2** с использованием препроцессора **SCSS**. Проект представляет собой SPA (Single Page Application) с реактивным управлением состоянием игрового поля, анимациями перемещения костяшек и автоматической генерацией гарантированно собираемых комбинаций.

## Стек технологий
* **Фреймворк:** Vue 2 (Options API)
* **Стилизация:** SCSS (Sass), CSS-анимации
* **Сборка и деплой:** Webpack, GitHub Pages

---

## 🎮 Игровой процесс (Gameplay)

Игра ведется на квадратном поле размером **4×4** с 15 квадратными костяшками, пронумерованными от 1 до 15, и одной пустой ячейкой.
1. **Цель игры:** Перемещая костяшки по полю (используя пустую ячейку), упорядочить их по возрастанию номеров — слева направо и сверху вниз, начиная с 1 в левом верхнем углу. Пустая ячейка в конце должна оказаться в правом нижнем углу.
2. **Перемешивание:** Кнопка «Новая игра» или «Перемешать» сбрасывает текущий прогресс и случайным образом распределяет числа. 
3. **Победа:** Как только все костяшки встают на свои целевые позиции, игра фиксирует победу, останавливает таймер и выводит поздравительное уведомление.

### Управление
* **Клик мыши / Тап:** Нажатие на костяшку, расположенную по соседству с пустой ячейкой (по вертикали или горизонтали), сдвигает её на свободное место. Клик по костяшкам, у которых нет рядом пустой ячейки, игнорируется.

> 💡 **Математическая корректность:** В алгоритме генерации поля учтено правило четности. Игра генерирует только те случайные комбинации, которые физически **возможно собрать**, исключая неразрешимые состояния.

## 🏗 Архитектура и структура компонентов Vue

Логика приложения декомпозирована на реактивные компоненты:

### 1. `App.vue` (Корневой компонент)
Управляет глобальным состоянием игры.
* Хранит состояние игрового процесса (статус: идет игра, победа, не начата).
* Содержит счетчик ходов и логику таймера времени.

### 2. `GameBoard.vue` (Игровое поле)
Основной компонент, отвечающий за сетку 4×4.
* Хранит одномерный или двумерный массив элементов (например, от `1` до `15` и `0` для пустой ячейки).
* Содержит метод проверки возможности хода: вычисляет индексы текущей костяшки и пустой ячейки, проверяя, находятся ли они на одной линии и соседствуют ли друг с другом.
* Реализует метод проверки победы (`checkWin`) после каждого успешного хода.

### 3. `GameTile.vue` (Компонент костяшки)
Отвечает за визуальное отображение отдельного числового блока.
* Принимает через `props` текущий номер и его позицию.
* Динамически вешает CSS-классы для анимации перемещения (транзишены).

## 🛠 Локальный запуск и развертывание

Для запуска проекта на локальном компьютере выполните следующие команды:

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:Gh0st0fwAr/blackwalltask.git
   cd blackwalltask
Установите зависимости:

Bash
npm install
# или с помощью yarn
yarn install
Запустите сервер для разработки (с hot-reload):

Bash
npm run dev
# или
yarn dev
После этого откройте в браузере адрес, выведенный в терминале (например, http://localhost:8080).

Сборка проекта для продакшна (Production):

Bash
npm run build
# или
yarn build
